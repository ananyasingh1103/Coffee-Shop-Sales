# ☕️Coffee Shop Sales Analysis Dashboard

## Concise Description

Coffee Shop Sales Analysis Dashboard – A data analytics project built using Microsoft Excel to analyze transactional sales data, develop KPIs, and create an interactive dashboard for monitoring revenue, product performance, and time-based sales trends.

---

## Purpose

This project focuses on transforming raw sales data into meaningful business insights using Microsoft Excel’s data analysis and visualization capabilities.

The dashboard enables stakeholders to:

* Monitor total revenue and sales trends
* Track key performance indicators (KPIs)
* Identify top-selling products
* Analyze peak sales hours
* Compare store-level performance

This project demonstrates practical skills in Data Analysis, Dashboard Design, and Business Reporting using Excel.

## Features / Highlights

### Business Problem

Coffee shop management requires structured reporting to:

* Monitor overall revenue performance
* Identify high-performing products
* Understand peak sales hours
* Compare store-level profitability
* Improve inventory and staffing decisions

Manual data tracking makes it difficult to identify trends quickly and accurately.

---

### Goal of the Dashboard

* Provide centralized sales monitoring
* Track important KPIs in one view
* Analyze revenue trends over time
* Identify top-performing products
* Enable interactive filtering using slicers

---

### Walkthrough of Key Components

KPI Section:

* Total Revenue

* Total Quantity Sold
* Average Order Value

Sales Trend Analysis:

* Daily and Monthly Revenue Trends
* Time-based sales distribution

Product Performance Analysis:

* Revenue by Product Category
* Top-Selling Products

Store-Level Analysis:

Interactive Features:

* Slicers for Store Location
