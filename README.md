# ☕️Coffee Shop Sales Analysis Dashboard

**Coffee Shop Sales Analysis Dashboard** – An end-to-end Business Intelligence project built using Power BI to analyze sales transactions, monitor KPIs, evaluate product performance, and generate data-driven business insights for operational decision-making.

---

## Purpose

This project focuses on transforming raw transactional data into actionable insights using **Data Cleaning, Data Modeling, DAX calculations, and Interactive Dashboard Development**.

The dashboard enables stakeholders to:

* Track revenue and sales growth trends
* Monitor key performance indicators (KPIs)
* Identify top-selling products
* Analyze time-based sales performance
* Compare store-level revenue performance

This project demonstrates practical implementation of **Business Intelligence, Data Analytics, and Data Visualization concepts**.

---

## Tech Stack

**Tools & Technologies Used:**

* **Power BI Desktop** – Data Visualization & Dashboard Development
* **Power Query (ETL)** – Data Cleaning & Transformation
* **DAX (Data Analysis Expressions)** – Calculated Measures & KPIs
* **Data Modeling** – Relationship Management & Schema Design
* **Microsoft Excel (.xlsx)** – Data Source

**Core Skills Applied:**

* Exploratory Data Analysis (EDA)
* KPI Development
* Sales Performance Analysis
* Dashboard Design & Storytelling
* Data-Driven Decision Support

## Features / Highlights

### 🔹 Business Problem

Coffee shop management requires structured reporting to:

* Monitor overall revenue performance
* Identify high-performing products
